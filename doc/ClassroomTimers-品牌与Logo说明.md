# ClassroomTimers 品牌与 Logo 说明

版本：v1.0  
品牌：ClassroomTimers  
域名：classroomtimers.app  
品牌主张：Make every minute visible.

## 1. 品牌策略

ClassroomTimers 的品牌角色不是“有趣的在线秒表”，而是教师在课堂中可以信任的节奏工具。

品牌人格：

- 清晰，但不生硬。
- 专业，但不企业化。
- 温暖，但不儿童化。
- 精准，但不制造压力。
- 现代，但不过度追逐视觉潮流。

Logo 需要同时适用于：

- 网站顶栏。
- 浏览器 favicon。
- PWA / App 图标。
- 全屏计时水印。
- 社交预览和教师分享页。
- 黑白打印与单色环境。

## 2. Logo 概念

标志采用“字母 + 产品动作 + 负空间”组合：

- 外部开放圆环形成字母 C，代表 Classroom 与 Countdown。
- 中心字母 T 代表 Timers，也像稳定的计时指针。
- 圆环右侧的缺口表示时间正在推进，而不是一个封闭静止的时钟。
- 暖橙圆点表示全班共享的“此刻”和教师需要抓住的注意力焦点。

该符号不是普通秒表轮廓，避免了顶部按钮、刻度盘和闹钟铃铛等同质元素，在 16 px 小尺寸下仍能识别。

## 3. 视觉构成

- 基础画布：128 × 128。
- 圆环中心：64 × 64。
- 圆环半径：44。
- 圆环开口：位于 3 点钟方向。
- 圆环与 T 的笔画：8 px，圆头。
- 焦点圆点：半径 6.5 px。
- T 位于视觉中心，保持垂直稳定。

符号的圆环、T 与焦点圆点必须保持固定比例，不单独拉伸或改变相对位置。

## 4. 标准配色

主版本：

- 环与 T：`#F5F5F7`。
- 焦点点：`#FF9F0A`。
- 背景：透明或 `#0B0B0C`。

单色深色：

- 全部元素：`#0B0B0C`。
- 背景：透明或白色。

单色浅色：

- 全部元素：`#FFFFFF`。
- 背景：深色。

绿色 `#30D158` 是产品运行状态色，不进入 Logo。

## 5. 组合方式

### 主横版

标志在左，`ClassroomTimers` 在右，用于网站顶栏、页脚和社交资料。

### 竖版

标志在上，品牌名与域名在下，用于品牌封面和展示材料。

### 仅标志

用于 favicon、App 图标、工具舞台水印和小尺寸界面。

### App 图标

使用圆角石墨背景，内部标志保留足够安全区。不要给标志增加外发光、厚阴影或高光质感。

## 6. 安全区与最小尺寸

安全区以焦点圆点直径 `x` 为单位：

- 标志四周至少保留 `1.5x`。
- 横版 Logo 四周至少保留 `1x`。
- 不让文字、按钮、边框或图片进入安全区。

最小尺寸：

- 仅标志：16 px。
- 横版屏幕显示：120 px 宽。
- 印刷标志：6 mm。

小于 24 px 时，优先使用 `mark.svg`，不使用完整横版。

## 7. 错误用法

- 不封闭 C 的开口。
- 不移动或删除橙色焦点点。
- 不把 T 改成秒表指针、铅笔、书本或毕业帽。
- 不使用彩虹、紫蓝渐变或多色圆环。
- 不增加 3D、描边、斜切、长阴影或玻璃效果。
- 不压缩、倾斜、旋转或改变标志比例。
- 不把运行绿替换成品牌橙。
- 不在复杂图片上直接使用低对比版本。

网站顶栏与页脚使用 `mark.svg` 加可控文本组合：`Classroom` 使用主文字白色，
`Timers` 使用品牌橙色。这样可以根据不同断点独立调整标志与文字比例，而不修改原始图像。

品牌概念板用于表达方向，正式产品应使用 SVG 文件，避免直接从概念板截图。

## 9. 图像生成记录

品牌概念板通过内置图像生成工具制作，最终方向使用：

- 类别：教育效率工具。
- 核心隐喻：开放的 C 形倒计时环 + T 形指针 + 共享时刻圆点。
- 视觉模式：克制的深色生产力界面。
- 主色：近黑、石墨、白、暖橙。
- 状态色：绿色只用于运行状态。
- 必须避免：普通秒表剪贴画、闹钟、毕业帽、儿童插画、Apple 商标和复杂渐变。
