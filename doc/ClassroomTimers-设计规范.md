# ClassroomTimers 设计规范

版本：v1.3  
设计方向：Apple-inspired clarity，强调克制、层级、材质感和即时反馈，不复制 Apple 的具体界面或商标元素。

## 1. 设计目标

ClassroomTimers 的设计首先服务课堂中的“远距离可读”和“操作不出错”，其次才是视觉风格。

体验关键词：

- Calm：运行时画面安静，不与课堂内容争夺注意力。
- Clear：每个状态只有一个最重要信息和一个主要动作。
- Immediate：打开即可使用，常用任务最多两次操作开始。
- Forgiving：暂停、继续、延长、重置等操作可理解、可恢复。
- Warm：专业但不冷漠，适合学校而不过度儿童化。
- Trustworthy：计时状态、提醒设置和系统能力始终明确。

## 2. 核心原则

### 2.1 时间是主角

- 计时舞台中，数字必须是视觉层级最高的元素。
- 运行时减少设置项、说明和装饰，只保留当前任务必要控制。
- 全屏模式只显示标签、时间、进度和控制，不显示导航、正文或广告。

### 2.2 内容优先于容器

- 卡片只用于表达分组、层级或可点击区域，不为装饰而添加。
- 不使用厚重边框、强阴影和大面积渐变。
- 通过留白、字号、透明度和材质层级建立秩序。

### 2.3 状态必须一眼可懂

- 准备：中性灰与品牌橙。
- 运行：绿色仅用于开始和运行确认。
- 暂停：品牌橙或中性强调。
- 紧急：最后 10 秒使用红色，并配合文字或节奏变化。
- 完成：明确显示 “Time’s up” / “时间到”，不能只改变颜色。

### 2.4 Apple 风格不是复制

可以借鉴：

- 大字号与清晰层级。
- 分段控件、轻量浮层、圆角和克制材质。
- 直接操控、连续反馈与自然动效。
- 系统字体、触控尺寸和辅助功能。

不应复制：

- Apple Clock 的具体布局、图标、动效细节或像素尺寸。
- Apple Logo、产品截图和系统专属资产。
- 为“像 Apple”而牺牲 Web 平台的一致性和可访问性。

## 3. 品牌视觉

### 3.1 Logo

主标志由三个元素组成：

- 开放的 C：Classroom、Countdown 与未完成的时间进度。
- 几何 T：Timers，同时作为指针和稳定的课堂轴心。
- 暖橙圆点：全班共同关注的“此刻”。

Logo 只使用品牌橙，不使用运行绿。绿色属于产品状态，不属于品牌识别。

### 3.2 品牌色

| Token | Hex | 用途 |
| --- | --- | --- |
| `brand-amber` | `#FF9F0A` | Logo 焦点、选中态、链接与品牌强调 |
| `canvas-black` | `#0B0B0C` | 主背景、全屏计时舞台 |
| `surface-1` | `#1C1C1E` | 卡片、浮层、分段控件 |
| `surface-2` | `#2C2C2E` | 悬停、选中容器、输入背景 |
| `label-primary` | `#F5F5F7` | 主文字与时间数字 |
| `label-secondary` | `#A1A1A6` | 次要说明 |
| `separator` | `rgba(255,255,255,.12)` | 分隔线与弱边框 |
| `running-green` | `#30D158` | 开始、运行和成功状态 |
| `warning-red` | `#FF453A` | 紧急、停止、危险操作 |
| `focus-blue` | `#64D2FF` | 键盘焦点与辅助状态 |

使用比例建议：

- 近黑与石墨中性色：85%。
- 白与灰文字：10%。
- 品牌橙：4%。
- 绿、红、蓝状态色合计：1%。

### 3.3 色彩规则

- 品牌橙用于识别和选择，不与运行绿混用在同一个主要按钮中。
- 红色只表示停止、错误和时间紧急，不用于普通强调。
- 所有文字和图标必须满足 WCAG 2.2 AA 对比度。
- 状态信息不能只依赖颜色，必须同时提供文本、图标、位置或声音。
- 深色模式为工具舞台的默认模式；后续可为内容区增加浅色模式，但全屏计时仍以深色高对比为主。

## 4. 字体与数字

### 4.1 字体栈

普通界面使用系统字体，计时数字使用 Inter，并提供系统回退：

```css
--font-ui: ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont,
  "Segoe UI", sans-serif;
--font-number: "Inter", ui-sans-serif, system-ui, sans-serif;
--font-mono: ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace;
```

数字规则：

- 倒计时与秒表主数字使用 Inter 400 和等宽数字特性 `tabular-nums`。
- 秒表的小数部分使用 Inter 400，并缩小到主数字的 72%。
- 时间中使用冒号 `:`，不使用装饰性分隔符。
- 大数字避免过紧字距，防止投影环境下粘连。

### 4.2 字号层级

| 角色 | 桌面 | 移动 | 字重 |
| --- | --- | --- | --- |
| Display Timer | `clamp(64px, 14vw, 180px)` | `clamp(52px, 18vw, 96px)` | 400 |
| Page Title | 48px | 34px | 600 |
| Section Title | 32px | 26px | 600 |
| Card Title | 18px | 17px | 500 |
| Body | 16px | 15px | 400 |
| Secondary | 14px | 13px | 400 |
| Label | 12px | 12px | 500 |

正文建议行高 1.6，工具标签行高 1.3，大数字行高 0.95–1。

## 5. 间距、圆角与布局

### 5.1 8 点间距系统

基础单位为 4 px，主要节奏使用 8 px：

`4 / 8 / 12 / 16 / 24 / 32 / 40 / 48 / 64 / 80 / 96`

规则：

- 相关控件间距：8–12 px。
- 一个组件内部：16–24 px。
- 相邻内容区：32–48 px。
- 页面章节：64–96 px。
- 移动端左右安全边距：16 px。
- 平板与桌面左右安全边距：24–32 px。

### 5.2 圆角

| Token | 数值 | 用途 |
| --- | --- | --- |
| `radius-sm` | 8px | 小按钮、标签 |
| `radius-md` | 12px | 输入、分段控件 |
| `radius-lg` | 16px | 卡片 |
| `radius-xl` | 24px | 面板与模板卡片 |
| `radius-pill` | 999px | 模式切换、圆形按钮 |

同一父容器内不要混用超过两种圆角。

### 5.3 页面网格

- 内容最大宽度：1280 px。
- 正文最大宽度：720–760 px。
- 工具舞台：最少占一个可视窗口减去导航高度。
- 桌面页面网格：12 列，24 px gutter。
- 平板：8 列，20 px gutter。
- 手机：4 列，16 px gutter。

断点：

- `sm`：640 px。
- `md`：768 px。
- `lg`：1024 px。
- `xl`：1280 px。

不要按设备名称做逻辑判断，应按可用空间和输入方式适配。

## 6. 材质与层级

层级从低到高：

1. Canvas：`#0B0B0C`。
2. Surface：`#1C1C1E`。
3. Raised Surface：`#2C2C2E`。
4. Popover：`rgba(44,44,46,.92)` + 适量背景模糊。

规则：

- 背景模糊只用于顶栏、浮层和上下文菜单。
- 普通卡片不使用玻璃拟态。
- 阴影只用于浮层与模态层，工具卡片依靠色差和弱边框。
- 边框使用 1 px 半透明分隔，避免高亮白线。

推荐阴影：

```css
--shadow-popover: 0 16px 48px rgba(0, 0, 0, 0.36);
--shadow-focus: 0 0 0 3px rgba(100, 210, 255, 0.36);
```

## 7. 核心组件规范

### 7.1 顶部导航

- 桌面：Logo 左置，主工具使用居中的分段控件，语言等辅助操作右置。
- 顶部一级菜单固定为 Home、World Clock、Flip Clock、Digital Clock、Stopwatch。
- Egg Timer、Candle Timer、Visual Timer、模板页和 SEO 时长页不进入顶部一级菜单。
- 不使用 Mega Menu；二级能力统一收进对应一级工具页面。
- 手机：Logo 与菜单同一行，五个一级入口进入一个简洁菜单。
- 高度：桌面 64 px，手机 56 px。
- 滚动时使用半透明背景和 16–24 px 模糊。
- 当前工具必须同时通过背景、文字色和 `aria-current` 表达。
- 语言切换器属于辅助操作，不能挤压五个一级入口；移动端可放在导航旁或简洁菜单中。

一级页面内部的二级入口：

- 使用“Styles”“Popular timers”“Related tools”等清楚标题。
- 默认只显示 4–8 个最相关入口，更多内容通过一个 “View all” 链接收束。
- 优先使用文字链接、紧凑按钮或低密度小卡片，不做满屏卡片墙。
- 链接区宽度建议不超过 960 px，单个章节高度不超过普通首屏的 50%。
- 在链接区前后保留 48–80 px 垂直留白，让主工具、正文与链接之间有明显节奏。
- 不使用关键词标签云，不重复堆放近义词，不让 SEO 链接抢过主操作。

### 7.2 分段控件

- 只用于 2–5 个互斥模式。
- 容器高度 36–40 px。
- 选中项使用抬升表面和轻微内阴影，不使用亮色大面积填充。
- 切换应在 160–220 ms 内完成。
- 移动端无法完整容纳时允许横向滚动，不缩小到不可读。

### 7.3 主要按钮

- 课堂执行页优先使用圆形或胶囊形大按钮。
- 最小触控区域：44 × 44 px；主要执行按钮建议 72–96 px。
- 一个状态最多有一个绿色主要动作。
- 停止/暂停使用红色语义，重置使用中性语义。
- 按下反馈使用 `scale(.97)`，持续 80–120 ms。

### 7.4 输入与滚轮

- 时间滚轮仅在准备态显示。
- 当前选中值有清晰横向选区，不依赖透明渐隐判断。
- 文本输入必须有可见标签，不能只使用 placeholder。
- 修改时间后立即更新预览，但不得自动开始。

### 7.5 预设卡片

每张卡片只包含：

- 时长。
- 场景名称。
- 一个启动动作。
- 可选的收藏或更多菜单。

整个卡片可点击启动时，删除或收藏按钮必须有独立点击区域，避免误触。

### 7.6 浮层与模态面板

- 桌面优先使用锚定浮层或右侧轻面板。
- 手机使用底部 Sheet。
- 打开后焦点进入面板，关闭后返回触发按钮。
- Escape 关闭；背景点击是否关闭需按风险决定。
- 删除、清空等不可逆操作需明确确认。

### 7.7 Toast

- 用于复制链接、保存预设和轻量系统反馈。
- 默认显示 2.5–4 秒。
- 不遮挡底部主要按钮。
- 错误反馈必须保留到用户理解或主动关闭。

### 7.8 Settings 入口与面板

- 只要工具存在两个及以上可配置项，就必须提供 Settings 按钮。
- Settings 固定在工具舞台右上角，与全屏、常亮组成克制的辅助操作组。
- 图标按钮必须有可访问名称和 Tooltip；不能只显示无标签齿轮。
- 桌面使用锚定 Popover 或右侧轻面板，手机使用底部 Sheet。
- 面板按“Appearance / Sound / Display / Behavior”分组，只显示当前工具相关选项。
- 修改后实时预览，并提供“Reset to defaults”。
- 常用设置自动本地保存，不要求额外点击 Save。
- 可分享的视觉与计时配置可以写入 URL；音量、Wake Lock、设备权限等偏好不得默认进入分享链接。
- 设置关闭后，焦点返回 Settings 按钮。

### 7.9 Flip Clock 风格与背景

MVP 至少提供以下四种风格：

- Classic：高对比黑色翻页牌。
- Minimal：无明显机械边框的纯净数字卡。
- Soft：圆角更柔和、对比略低的课堂常显版本。
- Paper：暖色浅背景与深色字，适合明亮教室。

MVP 至少提供以下六种预设背景：

- Black。
- Graphite。
- Midnight Blue。
- Deep Forest。
- Warm Ivory。
- Classroom Slate。

规则：

- 风格控制数字卡、字重、分隔线和翻页材质；背景控制画布，不把两者混成不可预测的自由主题。
- 每个组合都必须保证远距离可读和 AA 对比度。
- 风格与背景用缩略预览选择，不只用抽象名称。
- 切换风格不得重置 12/24 小时制、秒数和全屏状态。
- MVP 不支持上传图片背景，避免隐私、对比度与性能问题。

### 7.10 Egg Timer 与 Candle Timer

Egg Timer：

- 以沙粒、液面或填充高度表达剩余比例。
- 时间数字仍必须保留，视觉隐喻不能成为唯一信息。
- 动画连续但低刺激，不模拟高频颗粒物理效果。

Candle Timer：

- 用蜡烛高度或燃烧进度表达剩余时间。
- 火焰保持克制，不能持续大幅摇摆、发光或产生烟雾遮挡。
- 适合阅读与安静活动，默认声音应为静音或柔和提示。
- `prefers-reduced-motion` 下改为静态高度分段更新。

### 7.11 Digital Clock 风格与背景

MVP 至少提供以下四种风格：

- Minimal：轻字重、留白充足的纯数字显示。
- Segment：克制的七段数码管观感。
- Dot Matrix：低密度点阵显示，避免高频闪烁。
- Classroom：高对比、大字重、适合投影的课堂模式。

MVP 至少提供 Black、Graphite、Midnight Blue、Deep Forest、Warm Ivory、Classroom Slate 六种预设背景。

规则：

- 主题负责数字造型、字重、分隔符与日期排版；背景负责画布色彩和轻纹理。
- 日期、星期、秒数与 12/24 小时制在 Settings 中独立控制。
- 切换主题或背景不能中断时钟，也不能重置显示设置。
- 每种组合都必须保持远距离可读、AA 对比度和稳定的数字宽度。
- MVP 不提供用户上传背景。

## 8. 计时舞台

### 8.1 准备态

结构顺序：

1. 场景标签。
2. 时间预览与进度容器。
3. 取消/开始。
4. 时间设置。
5. 最近使用或课堂预设。

### 8.2 运行态

- 隐藏不必要的设置。
- 时间数字居中，标签在上方。
- 进度环为辅助信息，不能压缩数字。
- 提供暂停和增加/减少 1 分钟。
- 全屏后控件可在无操作 3 秒后降透明度，鼠标移动、触摸或键盘操作时恢复。
- 不自动隐藏键盘焦点。

### 8.3 最后 10 秒

- 数字与进度切换为红色。
- 可选择每秒轻提示，但默认不连续播放高刺激声音。
- 5 秒和 0 秒可有轻微缩放脉冲。
- 开启 `prefers-reduced-motion` 时取消缩放，只保留颜色与文本。

### 8.4 完成态

- 显示 “Time’s up” / “时间到”。
- 提供“重新开始”和“完成”两个动作。
- 结束声音播放一次或按用户选择播放，不能无限循环且无明显关闭入口。
- 浏览器拒绝声音时用整屏边缘闪烁和文字提示回退。

## 9. 动效与反馈

动效原则：

- 动效解释状态变化，不用于制造“高级感”。
- 计时数字本身不做持续漂浮、发光或弹跳。
- 大面积模糊和渐变动画禁止用于工具舞台。

时长：

| 类型 | 时长 |
| --- | --- |
| 按钮按下 | 80–120 ms |
| Hover / 颜色 | 120–180 ms |
| 分段切换 | 160–220 ms |
| Sheet / Popover | 220–280 ms |
| 页面进入 | 240–320 ms |

缓动：

- 标准：`cubic-bezier(.2, .8, .2, 1)`。
- 退出：`cubic-bezier(.4, 0, 1, 1)`。
- 进度环使用线性更新，不使用弹性缓动。

## 10. 声音与触觉

- 首次播放声音必须由用户操作触发。
- 设置中提供试听。
- 默认音量应克制，不能突然达到系统最大音量。
- 声音选项使用语义名称：Bell、Chime、Soft Tone。
- 静音模式必须有视觉完成反馈。
- 震动仅在支持的移动设备上作为补充，不作为唯一提醒。
- 音效由项目直接下载并随站点本地部署，不在运行时请求第三方音频。
- 首选 [Mixkit Free Sound Effects](https://mixkit.co/license/)，[Pixabay Sound Effects](https://pixabay.com/service/license-summary/) 作为备选；只采用许可明确允许商业项目使用的素材。
- 下载时记录素材页面、作者、许可链接和下载日期，并保留原始许可凭证。
- 音效入库前统一裁剪静音、归一化响度并压缩，避免不同提示音音量突然跳变。

### 10.1 背景资产

- 预设背景优先使用 CSS 色彩、轻纹理和原创生成素材，减少版权、体积与可读性风险。
- 只有当主题确实需要照片时才使用 [Unsplash](https://unsplash.com/license) 等许可明确的图库，并将图片下载到项目内，不使用远程热链。
- 背景入库前生成适合桌面、移动和高分屏的尺寸，优先使用 AVIF/WebP，并保留合理的回退格式。
- 每张背景都必须通过时间数字对比度检查；必要时使用稳定的遮罩，不依赖图片本身碰巧提供暗区。
- MVP 不开放用户上传背景。

## 11. 世界时钟与时区表达

- 世界时钟必须同时回答“当地几点”“和我相差多久”“为什么日期不同”。
- 城市卡显示本地时间、日期、UTC 偏移、相对本地时差和 DST 状态。
- 多时区国家使用多个代表城市，不显示一个误导性的“国家时间”。
- 地图用于理解昼夜与地理关系，不能成为选择城市的唯一方式。
- 城市管理面板支持按城市、国家和时区搜索。
- 默认只展示 6–8 张城市卡，避免把所有重点国家铺满首屏。
- 工具下方用易读短章节解释 Time zone、UTC/GMT、DST 和 International Date Line。
- 时区说明与城市列表必须服务端可读，核心概念不能只存在于交互浮层。

## 12. 多语言设计

MVP Locale：`en`、`zh`、`zh-hant`。

规则：

- 英语使用根路径，其他语言使用 Locale 目录。
- 所有语言保持同一信息架构和功能，不为单个语言创造独立导航。
- 按钮不能依赖固定宽度；德语等较长文本允许自然扩展。
- 日语与中文不强制使用英文大写或字符间距。
- 时间、数字、日期、城市名和 12/24 小时制按 Locale 格式化。
- 翻译覆盖工具 UI、Settings、错误、Toast、元数据、正文、FAQ 和结构化数据。
- 缺失翻译不得静默混用其他语言；开发环境应明确暴露缺失 key。
- 语言选择器显示当前语言名称，不使用国旗代表语言。
- 切换语言时尽量保留当前工具路径和可分享配置参数。
- 移动端语言选择器属于辅助操作，不增加新的一级工具项。

## 13. 响应式行为

### 手机

- 主要动作固定在可触达区域，但不能遮挡内容。
- 时间设置与预设纵向排列。
- 工具导航可以横向滚动。
- 避免需要 Hover 才出现的操作。

### 平板

- 横屏是课堂主场景，应优先验证。
- 设置可用右侧面板，时间舞台保持居中。
- 预设可在底部横向滚动。
- 适配浏览器工具栏与安全区域。

### 桌面与投影

- 时间数字不应无限放大，保留安全边距。
- 控件和数字应在 16:9 与 4:3 投影比例中都保持平衡。
- 高分辨率屏幕不通过缩小控件来增加密度。

## 14. 可访问性

必须：

- 所有功能可通过键盘完成。
- 焦点环在深色背景上清楚可见。
- Space 开始/暂停，R 重置，F 全屏，方向键或 `+/-` 调整时间。
- 快捷键不得在文本输入聚焦时误触发。
- 使用 `aria-live` 宣布暂停、恢复和完成，不每秒朗读剩余时间。
- 图标按钮必须有可访问名称。
- 对话框管理焦点并支持 Escape。
- 尊重 `prefers-reduced-motion`、系统字体缩放和高对比设置。
- 200% 页面缩放时核心流程仍可完成。

## 15. 内容与文案

语气：

- 短、直接、平静。
- 使用教师熟悉的场景词，不使用技术术语。
- 先写结果，再写能力。

推荐：

- “Start timer”
- “Add 1 minute”
- “Keep screen awake”
- “Copy classroom link”
- “Time’s up”

避免：

- “Execute”
- “Initialize”
- “Engage immersive experience”
- 大量感叹号、拟人化或幼稚口吻。

按钮使用动词，设置项使用名词或状态，错误信息说明“发生了什么 + 如何继续”。

## 16. SEO 与语义结构

- 每页只有一个主要 H1。
- 工具本体使用 `section`，说明内容按 H2/H3 分层。
- FAQ 使用 `dl` 或语义明确的折叠结构。
- 预设列表使用 `ul`。
- 主要交互必须使用 `button`，页面跳转使用 `a`。
- 工具下方的正文、FAQ 和内链应服务端渲染。
- 长尾链接放在对应一级页面内部，以真实任务分组，每组默认展示 4–8 个。
- 首页第二屏链接到 `/egg-timer`、`/candle-timer`、Visual Timer、常用时长页和已上线的课堂互动工具。
- `/digital-clock` 与 `/flip-clock` 在各自页面内提供主题、背景及相关显示能力。
- 每个 Locale 输出 canonical、hreflang 和 `x-default`，不把自动跳转页设为 canonical。
- 不为了关键词密度牺牲自然文案。

## 17. 设计验收清单

- 首屏 5 秒内能判断当前工具与主要动作。
- 常用课堂计时最多两次操作开始。
- 教室后排可清楚读取时间。
- 运行、暂停、紧急和完成状态不只依赖颜色。
- 手机、平板横屏、桌面、16:9 和 4:3 投影均无关键遮挡。
- 所有主要按钮触控区域不小于 44 px。
- 键盘焦点清晰，快捷键不与输入冲突。
- 全屏模式无导航、正文、广告或无关操作。
- 关闭声音后仍能感知完成。
- Logo、橙色品牌强调与绿色运行状态职责分离。
- 顶部导航只保留 Home 与四个一级工具，二级与长尾链接在对应页面内部保持低密度布局。
- 所有需要配置的工具都有一致的 Settings 入口。
- Flip Clock 风格和背景的任意组合均保持远距离可读。
- World Clock 清楚表达 UTC 偏移、时差、日期偏移与 DST。
- 英语、简体中文与繁体中文不出现关键界面漏译或语言混用。
- 没有无意义渐变、玻璃拟态堆叠或复杂动画。
- 页面视觉与交互遵循现有组件模式，不为局部改动引入新的全局系统。
